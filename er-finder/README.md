# er-finder — 가까운 응급실 찾기 (경북, 오프라인 동작 웹앱)

지금 위치에서 **차로 가장 빨리 닿는 응급실**과 **가장 가까운 권역응급의료센터**를 보여 주는 웹앱입니다.
[er-access](../er-access)가 1 km 칸마다 도로망으로 미리 계산한 이동 시간을 그대로 씁니다.

[가까운 응급실](https://0ju12.github.io/data-projects/near/) · 휴대폰에서 "홈 화면에 추가" 하면 앱처럼 열리고, 한 번 열어 두면 인터넷 없이도 찾기가 됩니다.

## 하는 일

- **내 위치로 찾기**(브라우저 위치) 또는 **지도에서 누르기** → 그 칸의 이동 분과 가장 가까운 응급실
- 가장 빠른 응급실과 가장 가까운 권역센터가 같으면 카드 하나로 합침
- 카카오맵 길찾기, 네이버 지도, 구글 지도 길찾기 링크 · 맨 위에 119 전화 버튼
- 사람이 살지 않아 계산하지 않은 칸(산·논 한가운데)이면 3칸 안 가장 가까운 칸으로 계산하고 그렇다고 알려 줌
- 경북 밖이면 계산 범위 밖이라고 알리고, 직선 거리로 가까운 곳만 보여 줌
- 병상 스냅숏(`er-access korea-fetch` 로 모은 실시간 가용 병상)이 있으면 가장 최근 값을 함께 표시
- 위치는 기기 안에서만 씀 (서버 없음, 어디로도 보내지 않음)

## 구성

| 파일 | 하는 일 |
|---|---|
| `build.py` | `er-access/docs/finder.json` → `docs/grid.json` (칸 번호·분×10·응급실 번호를 정수 배열로, 52만 B → gzip 15만 B) |
| `docs/finder.js` | 칸 찾기·빈 칸이면 가까운 칸으로·대상별 결과·길찾기 링크 (브라우저와 node 테스트 공용) |
| `docs/index.html` | 화면. MapLibre 지도는 온라인일 때만, 찾기는 오프라인에서도 |
| `docs/sw.js`, `manifest.webmanifest`, `icons/` | 설치형 웹앱(PWA): 화면·로직·격자를 미리 저장, 격자는 온라인이면 새 것으로 |

## 한계

- 응급실 목록은 **임시 목록 18곳**(권역센터 5곳 + OSM 등)입니다. 공식 목록을 받으면(`korea-fetch`) er-access 를 다시 계산하고 `python build.py` 를 다시 돌립니다.
- 이동 시간은 도로 등급별 제한속도로 **막힘 없이** 달린다고 본 값입니다. 신호·정체·회전 제한이 없어 실제로는 더 걸립니다.
- 응급실이 지금 진료할 수 있는지는 모릅니다. 화면에 "가기 전에 전화나 119 로 확인" 을 적어 두었습니다.

## 실행

```bash
python build.py                 # er-access 를 다시 계산한 뒤
python -m pytest -q             # 5개 (격자 압축, 병상 스냅숏, PWA 파일 짝, node 로 finder.js 4개)
```

로컬에서 볼 때는 `python -m http.server` 로 docs 를 열면 됩니다 (127.0.0.1 은 위치 권한·서비스 워커가 동작하는 보안 출처).
