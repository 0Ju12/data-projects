# er-access — 응급실까지 몇 분 걸리나: 응급의료 사각지대 찾기

> **상태: 뼈대 단계.** 계산 엔진과 테스트는 돌아가지만, 실제 응급의료기관 목록을 아직 넣지 않아 결과 숫자는 없습니다.

1 km 격자마다 **가장 가까운 응급실까지의 차량 이동 시간**을 도로망으로 계산하고,
보건복지부의 응급의료 취약지 기준(지역응급의료센터 30분, 권역응급의료센터 60분) 안에 닿지 못하는 인구를 셉니다.
첫 분석 지역은 경상북도입니다(`config.json` 에서 바꿀 수 있음).

## 흐름

```
WorldPop 1 km 인구 (XYZ CSV) ──────────────────────────────┐
OSM 도로 (Overpass) ─► 등급별 속도 · 일방통행 · 제한속도 ─► 도로 그래프 ─┼─► 응급실에서 거꾸로 퍼지는 다익스트라 ─► 칸별 분 ─► 기준 시간 안 인구 비율
응급의료기관 목록 (공공데이터포털) ─► 종별 정리 · 중복 제거 ─────────┘
```

## 자료 받기

| 자료 | 받는 곳 | 이 실행 환경에서 |
|---|---|---|
| 응급의료기관 목록 | 공공데이터포털 [국립중앙의료원_전국 응급의료기관 정보 조회 서비스](https://www.data.go.kr/data/15000563/openapi.do) (활용 신청 → 인증키) | ❌ 해외 IP 연결 끊김 → **한국에서** `fetch-er` 실행 |
| 격자 인구 | [WorldPop 2020 1 km (XYZ zip)](https://data.worldpop.org/GIS/Population/Global_2000_2020_1km/2020/KOR/kor_ppp_2020_1km_ASCII_XYZ.zip) | ✅ `fetch-pop` |
| 도로 | OpenStreetMap (Overpass API) | △ 미러 응답이 불안정, 재시도 필요 |

```bash
# 한국에서 (인증키는 '일반 인증키(Decoding)')
ER_API_KEY=발급받은키 python -m eraccess.cli fetch-er     # → data/er_list.csv, 이 파일을 커밋
```

API 응답 항목 이름은 명세서로 아직 확인하지 않았습니다. 그래서 받은 항목을 이름 그대로 모두 저장하고,
읽을 때 `eraccess/er.py` 의 별칭 목록(`기관명`/`dutyName`, `위도`/`wgs84Lat` …)으로 열을 찾습니다.
직접 내려받은 CSV(CP949 포함)도 열 이름이 비슷하면 그대로 읽힙니다.

## 계산 규칙과 가정

- **방향**: 칸 → 응급실 시간을 칸마다 따로 풀지 않고, 간선을 뒤집은 그래프에서 응급실들로부터 한 번에 퍼뜨립니다. 일방통행이 있어 '응급실 → 칸' 과 값이 다를 수 있기 때문입니다.
- **속도**: 도로 등급별 평균 속도 가정(고속도로 90, 국도 주간선 70, 주요 도로 50 … 주거 도로 25 km/h). 표시된 제한속도가 더 낮으면(스쿨존 30 등) 그쪽을 씁니다. 실제 정체는 반영하지 않습니다.
- **도로에 붙이기**: 칸 중심과 응급실을 1.5 km 안의 가장 가까운 도로 지점에 붙이고, 그 직선 거리를 20 km/h 로 환산해 더합니다. 1.5 km 안에 도로가 없는 칸은 '닿지 못함' 으로 셉니다(보수적).
- **범위**: 경북 경계 상자라 대구·울산 등 이웃 지역 인구가 섞입니다(상자 안 623만 명, 경북 인구는 약 260만 명). 경계 밖 응급실을 이용할 수 있게 일부러 넓게 두었고, 시군구 경계로 자르는 일은 다음 단계입니다.

## 다음 단계

1. 응급의료기관 목록 받기 → 첫 계산과 결과 표
2. 시군구 경계로 집계해 '취약지' (기준 밖 인구 30% 이상) 시군구 찾기, 공식 취약지 지정 목록과 대조
3. 지도 대시보드 (`docs/`)
4. (2단계) 실시간 가용 병상을 한국에서 정기 수집해 시간대·요일별 혼잡 예측

## 실행

```bash
python -m eraccess.cli fetch-pop       # WorldPop
python -m eraccess.cli fetch-roads     # OSM 도로
python -m eraccess.cli build           # → data/summary.json
python -m pytest -q                    # 10 passed
```

표준 라이브러리만 씁니다(테스트는 pytest). 큰 원본(`raw/`)은 저장소에 넣지 않습니다.
