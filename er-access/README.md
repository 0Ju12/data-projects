# er-access — 응급실까지 몇 분 걸리나: 경상북도 응급의료 사각지대

1 km 격자마다 **가장 가까운 응급실까지의 차량 이동 시간**을 OSM 도로망으로 계산하고,
보건복지부의 응급의료 취약지 기준(지역응급의료센터 30분, 권역응급의료센터 60분) 안에 닿는 인구를 셉니다.

**직접 보기 → [응급실 접근성 3D 지도](https://0ju12.github.io/data-projects/er/)** (main 에 합쳐진 뒤 매일 배포에 포함)

> **지금 결과는 임시 응급실 목록으로 낸 것입니다.** 공식 응급의료기관 목록(국립중앙의료원)은 공공데이터포털이
> 이 실행 환경(해외 IP)에서 막혀 아직 받지 못했습니다. 대신 위키백과의 권역응급의료센터 표 5곳과 OSM 에
> 응급실로 표시된 병원 12곳(경계 상자 안)을 썼습니다. 실제 응급실은 이보다 훨씬 많으므로 **시간은 실제보다 길게** 나옵니다.

## 첫 결과 (임시 목록, 2026-11-24)

| 기준 | 경북 인구 중 기준 시간 안 |
|---|---|
| 권역응급의료센터 60분 | **91.5%** (256만 명 중 234만 명) |
| 응급실 아무 곳 30분 (임시 18곳) | 72.2% |
| 응급의료 취약 시군 (27% 기준, 권역센터 기준만) | **8곳 / 22** — 문경·봉화·상주·영덕·영양·울릉·울진·청송 |
| 지역응급의료센터 이상 30분 | 공식 목록 필요 (임시 목록엔 지역센터가 없어 계산하지 않음) |

- 응급의료 취약지 지정 기준은 '지역센터 30분' 또는 '권역센터 60분' 안에 닿지 못하는 인구가 **27% 이상**인 시군구입니다([청년의사 보도](http://www.docdocdoc.co.kr/news/articleView.html?idxno=3032113), 보건복지부 고시 제2024-261호). 지역센터 기준은 공식 목록이 있어야 판정할 수 있어, 지금 판정은 권역센터 기준만으로 한 것입니다(`summary.json` 의 `vulnerable.missing`).
- 권역센터 60분 기준으로는 **영양군(16%)·문경시(46%)·봉화군(48%)·상주시(61%)·영덕군(62%)** 이 낮고, **울진군은 0%** 입니다.
  울진은 인구 가중 중앙값으로 권역센터(안동병원·포항성모병원)까지 122분이 걸리는 것으로 나옵니다. 강원 강릉아산병원은 경계 상자 밖이라 넣지 않았습니다.
- '응급실 아무 곳' 의 울진·청송·영양 0%는 군 안의 응급실(예: 울진군의료원)이 임시 목록에 빠져서 생긴 값일 가능성이 큽니다.
  공식 목록을 넣으면 가장 크게 바뀔 부분입니다.
- 인구 합 256만 명은 WorldPop 2020 추정치를 경북 칸에 더한 값으로, 경북 주민등록 인구(260만 명대)보다 조금 적습니다.
- 울릉군은 섬 안 도로만으로 따로 계산합니다(울릉군보건의료원까지 인구 가중 중앙값 15분). 육지의 권역센터는 도로로 갈 수 없어 '못 닿음' 으로 세므로 권역센터 기준 취약으로 나옵니다. 실제 이송(배·헬기)은 반영하지 않습니다.

## 흐름

```
WorldPop 1 km 인구 (XYZ CSV) ─────────────────────────────────────────────────┐
HOT 한국 OSM 도로 (GeoPackage) ─► 등급·일방통행·좌표로 교차로 잇기 ─► 가장 큰 연결 도로망 ─┼─► 응급실에서 거꾸로 퍼지는 다익스트라 ─► 칸별 분
응급실 목록 (공식, 없으면 위키백과 권역센터 + OSM) ─► 종별 정리 · 같은 병원 합치기 ───────┘                    │
                                                         칸이 붙은 도로의 시군 (HOT 행정구역 + 보정) ─► 경북 칸만 집계 · 시군별 표
```

## 자료 받기

| 자료 | 받는 곳 | 이 실행 환경에서 |
|---|---|---|
| 응급의료기관 목록 (공식) | 공공데이터포털 [국립중앙의료원_전국 응급의료기관 정보 조회 서비스](https://www.data.go.kr/data/15000563/openapi.do) (활용 신청 → 인증키) | ❌ 해외 IP 연결 끊김 → **한국에서** `fetch-er` |
| 격자 인구 | [WorldPop 2020 1 km (XYZ zip)](https://data.worldpop.org/GIS/Population/Global_2000_2020_1km/2020/KOR/kor_ppp_2020_1km_ASCII_XYZ.zip) | ✅ `fetch-pop` |
| 도로 | HDX [hotosm_kor_roads](https://data.humdata.org/dataset/hotosm_kor_roads) (OSM 한국 전체, GeoPackage 약 380 MB) | ✅ `fetch-roads` |
| 시·읍·면 이름 | HDX [hotosm_kor_populated_places](https://data.humdata.org/dataset/hotosm_kor_populated_places) | ✅ `fetch-places` |
| 임시 응급실 | OSM `amenity=hospital` + `emergency=yes` (Overpass), 위키백과 [권역응급의료센터](https://ko.wikipedia.org/wiki/권역응급의료센터) 표 | ✅ (저장소에 CSV 포함) |

```bash
# 한국에서 (인증키는 '일반 인증키(Decoding)'). 한 번에: 공식 목록 + 병상 한 번 + 다시 계산
ER_API_KEY=발급받은키 python -m eraccess.cli korea-fetch
# 병상만 정기 수집 (예: cron 매시 5분) → data/beds/YYYY-MM.csv 에 이어 붙임
5 * * * * cd ~/data-projects/er-access && ER_API_KEY=발급받은키 python -m eraccess.cli collect-beds
```

`data/er_list.csv` 를 커밋하면 다음 계산부터 공식 목록으로 바뀌고, '지역센터 이상 30분' 기준과 취약 판정이 함께 계산됩니다.
실시간 병상 API(`getEmrrmRltmUsefulSckbdInfoInqire`)의 응답 항목은 이름 그대로 모두 저장합니다. 명세상 `hvec` 가 응급실 가용 병상으로 알려져 있지만, 실제 응답으로 확인하기 전까지는 분석에 쓰지 않습니다.

처음엔 Overpass API 로 도로를 타일 단위로 받으려 했지만, 공용 서버들이 이 환경에서 연결을 끊거나 504(과부하)를 돌려줘
2시간 동안 64개 중 절반도 받지 못했습니다. HOT 가 HDX 에 올리는 나라 전체 내보내기로 바꿔 해결했습니다(`fetch-roads-overpass` 는 대안으로 남겨 둠).

## 계산 규칙과 가정

- **방향**: 칸 → 응급실 시간을 칸마다 풀지 않고, 간선을 뒤집은 그래프에서 응급실들로부터 한 번에 퍼뜨립니다. 일방통행 때문에 '응급실 → 칸' 과 다를 수 있기 때문입니다.
- **교차로 잇기**: HOT 내보내기에는 OSM 노드 번호가 없습니다. OSM 에서 교차로는 같은 노드(= 같은 좌표)를 공유하므로, 1e-7° 로 맞춘 좌표를 노드 번호로 써서 연결을 되살립니다. 입체교차는 노드를 공유하지 않아 잘못 이어지지 않습니다.
- **도로 등급**: 고속도로~마을길(unclassified)까지. 주거 도로는 메모리 때문에 뺐고, 그 때문에 끊긴 작은 조각(노드의 7%)은 버리고 **가장 큰 연결 도로망(93만 9천 지점)** 에만 칸과 응급실을 붙입니다.
- **속도**: 등급별 평균 속도 가정(고속도로 90, 국도 주간선 70, 주요 도로 50 … 마을길 30 km/h). HOT 파일엔 제한속도가 없습니다. 정체·신호는 반영하지 않습니다.
- **도로에 붙이기**: 칸 중심과 응급실을 1.5 km 안의 가장 가까운 도로 지점에 붙이고, 그 직선 거리를 20 km/h 로 더합니다. 1.5 km 안에 도로가 없는 칸(경북 인구의 2%, 대부분 산간)은 '못 닿음' 으로 셉니다.
- **경계**: 경로는 경계 상자 전체(대구·강원·충북 일부 포함)로 풀어 경계 밖 응급실도 쓸 수 있게 하고, 집계는 경북 칸만 합니다.
  칸의 시군은 칸이 붙은 도로의 HOT 행정구역을 따르되, HOT 표시의 오류를 바로잡습니다(`eraccess/region.py`): 울진군이 강원으로 표시 → 경북, 2023년 대구로 간 군위군과 대구 달성군·수성구 → 제외, 경북의 'Buk-gu' → 포항시.
- **시군 중앙값**: 인구 가중 중앙값. 못 닿는 칸은 '아주 멂' 으로 넣습니다(빼면 사각지대가 가려짐).

## 대시보드

`docs/index.html` — [deck.gl](https://deck.gl) 9 · [MapLibre GL JS](https://maplibre.org) 4 · [OpenFreeMap](https://openfreemap.org) 배경 지도 · Pretendard 글꼴 (모두 무료·키 없음).

- 1 km 칸마다 기둥: **높이 = 인구(제곱근)**, **색 = 이동 시간** (주황 한 색상 5단계, 라이트·다크 각각 대비 검증). 높고 밝은(다크) / 진한(라이트) 기둥이 '사람은 많은데 먼 곳' 입니다.
- 3D 기둥 ↔ 평면 전환, 응급실 종류 전환, 시군 표·'가장 먼 곳' 행을 누르면 그 위치로 날아감.
- 3D 표현은 Spencer Schien 의 인구 지도, Kontur 인구 + rayshader '스파이크 지도' 튜토리얼들, deck.gl ColumnLayer 예제를 참고했습니다.

## 실행

```bash
python -m eraccess.cli fetch-pop       # WorldPop
python -m eraccess.cli fetch-roads     # HOT 한국 도로 (약 380 MB → raw/, 저장소엔 넣지 않음)
python -m eraccess.cli fetch-places    # 시·읍·면 이름
python -m eraccess.cli build           # → data/summary.json, docs/data.json (약 35초)
python -m pytest -q                    # 23 passed
```

계산은 표준 라이브러리만 씁니다(테스트는 pytest). 큰 원본(`raw/`)은 저장소에 넣지 않습니다.
