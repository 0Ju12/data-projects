# crash-hotspots — 교통사고가 우연보다 많이 몰리는 곳 찾기

> **상태: 뼈대 단계.** 통계 엔진과 테스트는 돌아가지만, 실제 사고 자료를 아직 넣지 않아 결과 숫자는 없습니다.

사고 지점을 1 km 격자에 모아 **Getis-Ord Gi\*** 로 '이웃까지 합쳐 평균보다 유의하게 많은' 칸을 찾고,
칸이 수만 개라 생기는 우연한 핫스팟을 **Benjamini–Hochberg(거짓 발견 비율 5%)** 로 걸러 냅니다.
붙어 있는 핫스팟 칸은 한 구역으로 묶고, 마지막에 도로교통공단의 공식 사고 다발 지역과 겹치는지 대조할 계획입니다.

## 흐름

```
사고 CSV (연도별, CP949) ─► 열 이름 별칭 · 위경도 또는 UTM-K ─► UTM-K 1 km 격자 ─► Gi* z ─► BH 보정 ─► 맞닿은 칸 묶기 ─► 구역 목록
                                                                                                          │
                                                       공식 사고 다발 지역(표준데이터) ─► 겹침 대조 (다음 단계) ◄┘
```

## 자료 받기

공공데이터포털은 이 실행 환경(해외 IP)에서 연결이 끊겨, **한국에서 로그인 후 내려받아** `data/` 에 넣어야 합니다.

| 자료 | 받는 곳 | 쓰임 |
|---|---|---|
| 사고 한 건 단위 자료 | [공공데이터포털](https://www.data.go.kr) 에서 **"도로교통공단 사망 교통사고"** 검색 — 사고마다 일시·위경도(또는 UTM-K)·사고 유형이 있는 연도별 파일 | 분석 입력 → `data/crashes_<연도>.csv` |
| 공식 사고 다발 지역 | [전국교통사고다발지역표준데이터](https://www.data.go.kr/data/15029185/fileData.do) | 결과 대조 |
| (참고) 원천 | [TAAS 교통사고분석시스템](https://taas.koroad.or.kr) | 정의·통계 확인 |

- 지점 좌표가 공개된 것은 **사망 사고**뿐이라, 분석은 '사망 사고 다발 구간' 이 됩니다. 전국 5년치면 약 1만 건입니다.
- 사고 자료의 정확한 데이터셋 이름과 열 이름은 내려받은 뒤 확인합니다. 로더(`crash/load.py`)는 `위도`/`경도`, `발생위치X(UTMK)`/`발생위치Y(UTMK)`, `발생년월일시`, `사망자수`, `사고유형_대분류` 등의 별칭을 찾고, 좌표 열이 없으면 멈춥니다.

## 계산 규칙과 가정

- **좌표**: 격자는 UTM-K(EPSG:5179, 미터)로 만듭니다. 위경도 칸은 위도에 따라 넓이가 달라지기 때문입니다. 변환은 표준 횡메르카토르 공식으로 직접 구현했고, pyproj 와 0.1 mm 안에서 같습니다(테스트에 기준값).
- **이웃**: 칸 중심 사이 1.5 km 안 = 자신 + 맞닿은 8칸, 가중치 1.
- **분석 범위**: 사고가 한 번이라도 난 칸에서 1.5 km 안의 칸만 넣습니다. 바다·산지의 빈 칸이 평균을 끌어내려 도시 전체가 핫스팟이 되는 것을 막는 근사입니다. 도로가 있는 칸으로 범위를 정하는 것이 더 맞고, 다음 단계입니다.
- **다중 검정**: 균일하게 흩뿌린 가짜 사고 3,000건(1,600칸)으로 시험하면, 보정 없이 단측 0.05 로는 칸 58~121개가 '핫스팟' 으로 나오고 BH 뒤에는 0~1개만 남습니다(씨앗 10개).
- **사고 수 ≠ 위험도**: 교통량이 많은 곳은 사고도 많습니다. 이 분석은 '어디에 몰려 있나' 이고, 교통량 대비 위험도는 아닙니다.

## 다음 단계

1. 사고 자료 받기 → 첫 결과 (핫스팟 구역 목록, 사고 유형·도로 형태 구성)
2. 공식 다발 지역과 겹침 대조 (몇 %가 겹치고, 안 겹치는 곳은 왜인지)
3. OSM 도로가 있는 칸으로 분석 범위 바꾸기, 교통량 자료가 있으면 노출량으로 나누기
4. 지도 대시보드 (`docs/`)

## 실행

```bash
python -m crash.cli build      # data/crashes_*.csv → data/summary.json
python -m pytest -q            # 12 passed
```

numpy 만 씁니다(테스트는 pytest).
