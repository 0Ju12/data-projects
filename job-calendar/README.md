# job-calendar — 신입 IT 공고 달력

공개 공고판에서 매일 아침 개발·데이터 공고를 모아 **마감일 달력**으로 보여 주는 페이지입니다.
직무(백엔드·프론트엔드·모바일·데이터·AI·인프라·보안·임베디드·QA·게임), 경력(신입만 / 신입·표시 없음 / 전체), 출처, 지역, 검색어로 거르고,
관심 공고(★)의 마감일을 `.ics` 파일로 받아 휴대폰·구글 캘린더에 넣을 수 있습니다(마감 2일 전 알림 포함).

**보기 → https://0ju12.github.io/data-projects/jobs/**

## 출처와 수집 원칙

| 출처 | 받는 곳 | 마감일 | 신입 여부 |
|---|---|---|---|
| 점핏 | 신입(career=0) 공고 목록 API | 있음 | 목록 자체가 신입 |
| 카카오 채용 | careers.kakao.com 공개 API(`/public/api`) | 대부분 상시 | 제목으로 추정 |
| Greenhouse 공개 채용 API | 쿠팡·당근·크래프톤·몰로코·센드버드·퓨리오사AI 공고판 (국내 근무지만) | 대부분 상시 | 제목으로 추정 |

- **robots.txt 가 막지 않는 공개 API만** 씁니다(2026-11 확인). 원티드(robots.txt 가 `/api/` 를 막음), 토스(공고 목록 수집 금지)는 넣지 않았습니다.
- 하루 한 번, 출처마다 몇 쪽만 받고 요청 사이에 쉽니다. 공고 본문은 저장하지 않고 **제목·회사·근무지·마감일·링크**만 남깁니다.
- 출처 하나가 실패해도 나머지로 갱신하고, 실패한 출처의 공고는 지우지 않습니다.

## 처리 흐름

```
jobcal/sources.py   출처별 수집 → 같은 모양으로 정리 (id · 회사 · 제목 · 직무 · 신입 여부 · 등록일 · 마감일)
jobcal/classify.py  제목·분류 글자로 직무 9가지 + 기타 분류(여러 개 가능), 신입 여부(참·거짓·모름), 개발 직군 여부
jobcal/feed.py      data/postings.json 에 누적: 처음 본 날 유지, 마감 전인데 목록에서 사라지면 이틀 뒤 조기 마감으로 정리,
                    마감 지난 공고는 30일 보관 → docs/jobs.json
docs/index.html     달력(이번 주부터 5주) · 마감 순 목록 · 상시 공고 · 거르기 · ★ · .ics
```

## 한계

- 직무·신입 여부는 규칙으로 추정한 값이라 틀릴 수 있습니다. 경력 표시가 없는 공고는 '모름'으로 두고, 기본 화면은 신입과 '모름'을 함께 보여 줍니다.
- 대기업 공채(삼성·SK·LG·공기업 등)는 공개 API가 없어 빠져 있습니다. 이런 공채는 준비 공간의 '공채 정보' 탭에서 따로 정리합니다.
- 카카오·Greenhouse 공고는 마감일이 없는 상시 채용이 많아 달력보다 '상시 채용' 목록에 나옵니다.

## 실행

```bash
python -m jobcal.cli collect   # 수집 → data/postings.json · docs/jobs.json
python -m pytest -q            # 테스트 7개 (네트워크 없이, 저장된 응답 일부로)
```

매일 06:17(KST) `geo daily update` 워크플로가 수집하고, 같은 Pages 의 `/jobs/` 로 배포합니다.
