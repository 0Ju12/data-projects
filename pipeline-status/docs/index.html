    산출물마지막 갱신지난 시간기준상태

    숨은 실패: 매일 갱신 워크플로는 한 단계가 실패해도 다른 갱신을 계속하도록 continue-on-error 를 씁니다. 이때 작업은 성공으로 끝나고 API 의 단계 결과도 성공으로 바뀝니다. 그래서 성공한 작업의 실패 주석(annotation)을 읽고, 워크플로 안에서는 steps.*.outcome 을 직접 받아 찾습니다.

    알림: pipeline status 워크플로가 매일 갱신이 끝날 때마다 점검합니다. 빨간 문제가 있으면 pipeline-alert 이슈를 하나 엽니다. 문제가 바뀔 때만 이슈를 고치고, 모두 없어지면 닫습니다.

    표는 마지막 배포 때 만든 기록입니다. "새로 보기" 는 브라우저에서 GitHub API 로 실행 기록만 다시 받습니다 (로그인 없이 시간당 60번).
