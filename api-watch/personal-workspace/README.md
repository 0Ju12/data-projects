# Project Lab · 개인 개발·학습 기록

[개인 공간 열기](https://career-workspace-0ju12.affectionateimage.chatgpt.site/lab) · [공개 API 관제판](https://0ju12.github.io/data-projects/api-watch/)

프로젝트를 선택하고 관찰·학습 → 실험·해결 → 주간 회고 → 면접 설명으로 이어갑니다. 밝은 화면, 처음 사용 안내, 빈 기록 상태와 직접 입력한 결과를 구분합니다.

## 제공 기능

- 내 프로젝트의 목표와 실제 사용하는 API 선택
- 공식 AI 자료에서 실험 계획·학습 노트 시작, 기존 브라우저 메모 JSON 가져오기
- 실험 조건·기준선·직접 관측한 결과·비교 지표·한계, 장애 조치·검증·재발 방지 기록
- 같은 계정의 기기 간 서버 저장, 저장 충돌 차단, 미저장 입력 백업, 최근 20개 버전 복원
- 한국 날짜 기준 복습 예정일과 복습 완료 후 7일 뒤 재확인
- 실제 저장본의 기간별 주간 집계, 배운 점과 다음 행동 작성
- 완료 실험·해결 기록을 근거로 약 1분 답변 템플릿, 원본 버전 표시, 낭독 타이머
- 전체 최신 기록 JSON·Markdown 내보내기와 새 ID로 가져오기, 같은 가져오기 재시도 중복 방지

개인 기록은 이 공개 저장소에 저장하지 않습니다. Sites의 소유자 전용 인증과 기존 R2 문서 저장소를 사용하는 별도 서버에서 계정별로 보관합니다. 이 폴더에는 개인 데이터가 없는 구현 소스와 단위 테스트만 포함합니다.

## 검증

```sh
cd api-watch/personal-workspace
node --test lab.test.mjs client.test.mjs
```

서버 API·계정 분리·동시 저장·이력·가져오기·주간 회고·답변 근거와 클라이언트 저장 큐를 검증합니다. 실제 배포 프로젝트에서는 기존 지원 준비실 호환성과 생성된 Worker HTML·스크립트도 추가 검증합니다.

외부 LLM을 호출하지 않습니다. 자동 초안은 실제 기록을 조합한 템플릿이며 새로운 성과를 만들어내지 않습니다. 숫자 차이와 문자 수 기반 발화 시간은 참고이며 통계 검증·자동 면접 채점이 아닙니다.

이 서버 모듈은 Sites 인증 게이트가 전달한 사용자 헤더와 R2 `BUCKET` 바인딩을 전제로 합니다. 다른 호스팅에서 별도 인증 없이 사용자 입력 헤더만 신뢰해 배포하면 안 됩니다. 사이트 ID·접근 토큰·런타임 데이터는 이 폴더에 포함하지 않습니다.


## 오류·접근성 보완

입력 형식 검증, 끊긴 저장 응답의 확인·재시도, 동일 파일 재가져오기 중복 방지, 한글 UTF-8·연결 메타데이터를 포함한 크기별 전송, 보관 전 상태 복구, 자동 집계 기간 고정, 비동기 화면 이동 보호를 제공합니다. 가져오기는 12MB·최대 10,000개 기록이며 요청은 1.1MB 이하로 나눕니다.

개인 공간은 전체 이력이 제외된 `public/workspace.json`으로 연결합니다. 전체 관제 이력이 커져도 이 연결 파일은 불필요하게 늘어나지 않습니다. 이전 날짜 AI 자료와 오래된 검사 결과를 구분합니다. 공개 피드 오류가 개인 기록 목록을 막지 않습니다.

모바일 입력·터치 크기, 글자 대비, 본문 이동, 현재 메뉴와 저장 상태 안내를 보완했습니다. 로그인한 개인 화면의 실제 브라우저 조작은 단위·렌더링 검증과 구분해서 확인해야 합니다.

## 최신 준비 공간 연결

공개 프로젝트와 직접 작성한 AI 글은 커밋으로 고정한 `portfolio.json` 메타데이터로 연결합니다. 기존 개인 기록은 자동으로 덮어쓰지 않습니다. 통합 준비 공간은 https://0ju12.github.io/study/index.html 입니다.

통합 준비 백업은 지원 문서 보관함에서 가져옵니다. 암호화 백업의 비밀번호는 브라우저에서만 사용하며 서버로 전송하지 않습니다. 복호화된 기록은 본인 전용 저장소에 보관됩니다. 동일 파일 재가져오기는 기존 수정본을 덮어쓰지 않습니다.

### AI 자료실

`/lab#/library`에서 전체 기술 정리와 공식 자료 기반 학습 노트를 구분해 검색하고, 12개씩 탐색합니다. 자료별 학습 노트·실험 계획 버튼은 작성 대화상자를 열며, 직접 확인한 결과나 학습 완료를 자동 생성하지 않습니다. 공개 피드가 늦게 도착해도 검색어를 유지하고 목록을 갱신합니다. 배포본보다 오래된 공개 포트폴리오 피드로 최신 목록을 되돌리지 않습니다. 알고리즘 시각화 실습장과 공개 학습 데모로 이동할 수 있습니다.
