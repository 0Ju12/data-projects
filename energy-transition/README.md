# energy-transition — 한국 전력 전환을 공개 자료로 분석하기

Ember 월별 발전량과 Our World in Data 연간 에너지 자료로 질문 7개를 세우고, 질문마다 SQL 쿼리 하나로 답했습니다.
같은 저장소의 [전력 수요·채용 공고 분석](../warehouse/)이 2025년 한 해의 시간별 수요를 다뤘다면, 이 프로젝트는 그 수요를 무엇으로 채워 왔는지(발전 구성)를 25년 단위로 봅니다.

- **대시보드**: <https://0ju12.github.io/data-projects/energy/>
  - D3로 그렸고, 연도 재생·비교 나라 고르기·마우스 툴팁·표 보기를 지원합니다.
  - 밝은 화면과 어두운 화면을 모두 지원합니다.
- **자료**: [Ember Monthly Electricity Data](https://ember-energy.org/data/monthly-electricity-data/) · [OWID Energy dataset](https://github.com/owid/energy-data) (둘 다 CC BY 4.0, 키 없음)
- **도구**: Python(수집), DuckDB SQL(분석), D3(화면), pytest, GitHub Actions(매일 갱신)

## 질문과 답 (연간 2025년, 월별 2026년 9월 기준)

| # | 질문 | 답 | 쿼리 |
|---|---|---|---|
| 1 | 한국 발전 구성은 25년 동안 어떻게 바뀌었나? | 석탄 비중은 2009년 46.3%로 가장 높았고, 2025년 31.1%로 내려왔습니다. 그 자리는 가스(10.2% → 27.9%)와 태양광(6.1%)이 채웠습니다. 다만 석탄 발전량은 2010년대에 오히려 늘었습니다(218 → 261 TWh). | `sql/mix_yearly.sql` |
| 2 | 석탄 비중은 다른 나라보다 빨리 줄고 있나? | 2015 → 2025년 −11.3%p로, 비교한 12곳 중 7번째입니다. 영국(−22.3%p)·독일(−22.0%p)이 가장 빨랐고, 일본(−1.9%p)·대만은 한국보다 느렸습니다. | `sql/coal_change.sql` |
| 3 | 태양광은 언제, 얼마나 빠르게 늘었나? | 한국은 2017년에 1%, 2023년에 5%를 넘었습니다. 1%→5%에 걸린 6년은 같은 구간을 지난 나라들(4~11년)과 비슷합니다. 출발이 늦었을 뿐입니다. | `sql/solar_growth.sql` |
| 4 | 태양광 비중은 계절에 따라 어떻게 달라지나? | 2022~2025년 평균으로 5월 7.6%가 가장 높고 12월 3.4%가 가장 낮습니다. 해가 가장 긴 6~7월이 아니라 4~5월이 정점입니다. | `sql/solar_seasonal.sql` |
| 5 | 1년 안에서도 발전 구성이 바뀌나? | 석탄은 3월 25.2%로 가장 낮고 8월 34.9%로 가장 높습니다. 원자력 발전량은 달마다 거의 같아서, 전체가 작은 봄·가을에 비중만 오릅니다. | `sql/mix_monthly.sql` |
| 6 | 1kWh당 탄소는 줄고 있나? | 12개월 평균이 2020-01 491 g에서 2025-04 382 g까지 내려갔다가, 2026-09에 415 g으로 다시 올랐습니다. | `sql/intensity_monthly.sql` |

## 분석 노트

- **4번은 웨어하우스 분석의 이어지는 질문입니다.** 웨어하우스에서 평일 12~13시 수요가 새벽 최저보다 낮아진 날이 4월에 가장 많았습니다. 그때 "봄 낮의 자가용 태양광과 맞는 모양이지만 확인하지 못했다"고 남겼습니다. 이번에는 다른 자료(Ember)로 봤고, 전력망 태양광도 같은 봄에 비중이 가장 컸습니다. 다만 Ember 수치는 전력망에 잡히는 발전량이라 계량기 뒤 자가용 발전을 직접 재지는 않습니다. 두 자료가 같은 방향을 가리킨다는 데까지만 썼습니다.
- **비중과 발전량을 같이 봅니다.** 비중만 보면 석탄이 2010년대 내내 줄어든 것 같지만, 발전량은 그동안 늘었습니다. 대시보드 1번에 두 보기를 오가는 버튼을 둔 이유입니다.
- **원자력 비중의 계절 변화는 원자력이 바뀐 게 아닙니다.** 발전량은 달마다 14~16 TWh로 거의 같고, 분모(전체 발전량)가 작은 봄·가을에 비중이 올라갑니다.
- **3월에 석탄이 가장 적고 가스가 가장 많습니다.** 12~3월 미세먼지 계절관리제(석탄발전 가동 제한)가 영향을 줬을 수 있지만, 이 자료만으로는 효과를 따로 떼어 내지 못했습니다.
- **6번의 최근 반등**은 몇 달 더 봐야 일시적인지 알 수 있습니다.

## 자료를 다룬 방식

- **원본은 통째로 저장하지 않습니다.** Ember 월별 파일(약 30MB)과 OWID 파일(약 9MB)을 받으면서 비교 대상 12곳만 걸러 수백 KB로 줄입니다.
  - Ember는 2015년부터의 개별 발전원 9개와 합계만 남깁니다.
  - Fossil·Renewables 같은 묶음 행은 겹쳐 세지 않도록 버립니다.
- **받다가 실패하거나 열이 바뀌면 이전 파일을 그대로 둡니다.** 임시 파일에 다 쓴 뒤 바꿔치기하고, 정렬해 쓰므로 같은 원본이면 같은 파일이 나옵니다.
- **질문 하나에 쿼리 하나.** `sql/*.sql` 결과를 JSON으로 화면 틀에 넣어 정적 페이지 하나로 만듭니다. 화면의 답 문장도 이 결과에서 계산하므로, 자료가 갱신되면 문장도 같이 바뀝니다.
- **6개 묶음**: 석탄·원자력·가스·풍력·태양광, 그리고 수력·바이오·석유·기타를 합친 '기타'. 한국에서 각각 1% 안팎인 발전원을 따로 그리면 색만 늘어 읽기 어려워서 합쳤습니다.
  - 색은 색각 이상 시뮬레이션 검사를 통과한 조합만 썼습니다(밝은·어두운 화면 각각).
  - 대비가 낮은 노랑·청록에는 이름표와 표 보기를 함께 둡니다.

## 한계

- OWID 연간 수치는 여러 출처(Ember·Energy Institute)를 합친 것이라, 정부 통계(전력거래소·한전)와 소수점 단위로 다를 수 있습니다.
- 탄소 집약도는 발전 단계 배출 기준입니다. 연료 채굴·수송 같은 전 과정 배출은 포함하지 않습니다.
- 나라 비교는 12곳만 골랐습니다. 고른 기준은 `etl/sources.py`에 적었습니다.

## 실행

```bash
pip install -r requirements.txt
python -m etl.fetch      # 원본 받기 → data/*.csv (실패하면 이전 파일 유지)
python -m etl.analyze    # sql/*.sql → docs/index.html
python -m pytest -q      # 5개 — 거르기·형식 변경 대응·결정성·쿼리 답·페이지 생성
```

매일 실행은 저장소의 `geo-daily.yml`이 같은 명령을 부르고, 결과 페이지를 GitHub Pages의 `/energy/`에 올립니다.
