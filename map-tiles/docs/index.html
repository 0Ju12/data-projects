어떻게 만들었나

파이썬 표준 라이브러리만 씀 (tippecanoe·GDAL 없음)

  1. 세 프로젝트의 산출물(지진 목록, 산불 data.json, 응급실 격자)을 읽어 줌마다 웹 메르카토르 타일로 자릅니다. 타일 경계에서 원이 끊기지 않게 이웃 영역 64 단위를 겹쳐 넣습니다.
  2. 타일마다 MVT 2.1 을 protobuf 로 직접 인코딩합니다 (zigzag 좌표, 다각형 바깥 고리는 시계 방향).
  3. 모든 타일을 PMTiles v3 한 파일에 담습니다. 타일 번호는 힐베르트 곡선 순서이고, 같은 내용의 타일은 한 번만 저장합니다.
  4. 브라우저는 pmtiles.js 로 파일 앞 16 KB(머리글·목록)를 읽은 뒤 필요한 타일만 HTTP 범위 요청으로 받습니다. GitHub Pages 같은 정적 호스팅이면 됩니다.

검증: 테스트에서 공식 파이썬 구현(mapbox-vector-tile, pmtiles)으로 거꾸로 읽어 좌표·속성·타일 번호가 같은지 확인합니다.
